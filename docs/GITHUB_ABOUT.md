but **does not expose a repository-settings edit action**. Nothing here
implies that the About panel has already changed. In the GitHub repository's
**About → Edit** panel, the owner can use:

**Description (suggested):**

> Evidence-first open-source engineering analytics: 50 curated GitHub projects, verified Issue/PR/CI data, SQL checks, and Streamlit dashboards.

**Topics (suggested):**

`python`, `sql`, `streamlit`, `github-api`, `data-analytics`,
`github-actions`, `plotly`, `data-validation`

**Website:** Leave the field blank until a real hosted Streamlit URL is
verified. A local browser test or repository gallery is not a deployed demo.

**Repository name:** Keep `Granbe1l/beta-test` for now because existing
CV links, workflow URLs and chat monitoring may depend on it. Rename only
after planning and validating those redirects.

**License:** No license is being added without an explicit owner choice.
Publicly visible GitHub code is not automatically licensed for unrestricted
reuse. Choose a license intentionally if redistribution is desired.
